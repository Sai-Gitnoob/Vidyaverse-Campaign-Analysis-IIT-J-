# ViDya Verse E education platform Data Analysis:
Vidyaverse Ad Campaign Analysis 📊

Analyzing the effectiveness and ROI of Vidyaverse’s latest online course advertising campaign.

Project Overview

Vidyaverse, an online education platform, launched a new course and ran targeted ad campaigns. The goal of this project was to:

Evaluate whether the campaign successfully led to course enrollments.

Calculate the cost per successful course completion.

Approach & Methodology

Data Sources: Ad spend, click-through rates, and course enrollment data.

Tools Used: Python, Pandas, NumPy, Matplotlib, Seaborn.

Steps Taken:

Data Cleaning & Exploration – checked for missing values, anomalies.

Campaign Success Analysis – calculated conversions from clicks to course completions.

Cost Analysis – computed Cost per Successful Completion using:
